# 🎧 PCSoundToPhone

Передача звука с компьютера на Android‑телефон по Wi‑Fi в реальном времени.

Приложение на компьютере захватывает всё, что вы слышите в динамиках/наушниках, и отправляет по сети. Приложение на телефоне принимает поток и воспроизводит его через динамик телефона.

> Идеально для просмотра видео, музыки или игр на большом экране с выводом звука на телефон.

---

## ✨ Возможности

- 🖥️ **Linux (Arch)** — готовый bash‑скрипт, ничего собирать не нужно
- 🪟 **Windows** — PowerShell‑скрипт (WASAPI loopback)
- 🍎 **macOS** — bash‑скрипт (AVFoundation; для системного звука нужен BlackHole)
- 📱 **Android** — лёгкое приложение (API 21+, без Kotlin и внешних библиотек)
- 📡 Передача по **UDP** в формате `s16le` (16‑бит, стерео, 48000 Гц)
- ⚡ Минимальная задержка (настраиваемая)
- 📦 Готовый подписанный APK уже собран (17 КБ)

## 🚀 Быстрый старт

### Шаг 1. Узнайте IP телефона

На телефоне: **Настройки → Wi‑Fi → нажмите на подключённую сеть → IP‑адрес**  
(например, `192.168.1.42`). Компьютер и телефон должны быть в одной Wi‑Fi сети.

### Шаг 2. Запустите отправку на компьютере

#### Linux (Arch)
```bash
cd linux-sender
chmod +x pc-sound-sender.sh
./pc-sound-sender.sh 192.168.1.42 9999
```

#### Windows (PowerShell)
```powershell
cd windows-sender
.\pc-sound-sender.ps1 192.168.1.42 9999
```

#### macOS
```bash
cd macos-sender
chmod +x pc-sound-sender.sh
./pc-sound-sender.sh 192.168.1.42 9999
```

Остановка — `Ctrl+C`.

### Шаг 3. Установите и запустите приложение на телефоне

**Вариант А — готовый APK (рекомендуется):**

Скопируйте `PCSoundReceiver.apk` на телефон и откройте его. Или через USB (если включена отладка):
```bash
adb install -r PCSoundReceiver.apk
```

**Вариант Б — собрать из исходников:**

Откройте `android-receiver/` в Android Studio → *Build → Make Project* → *Run*.

На телефоне нажмите **«Старт»** — звук с компьютера пошёл в динамик телефона.

## 🔧 Настройка задержки (latency)

По умолчанию задержка ≈ 100–300 мс. Можно уменьшить:

**На Linux:** в `pc-sound-sender.sh` параметр `--latency-msec=20` уже установлен.  
Можно заменить на `--latency-msec=10` (ещё меньше задержка, но при слабом Wi‑Fi возможны перерывы).

**На Windows / macOS:** настройте буфер в соответствующем скрипте.

**На телефоне:** буфер `AudioTrack` и размер UDP‑пакета уменьшены до 2048 байт (уже учтено в APK).

## 🛠️ Решение проблем

| Проблема | Решение |
|----------|---------|
| Нет звука | Компьютер и телефон в одной Wi‑Fi сети? Порт `9999` свободен? Попробуйте временно отключить фаервол на компьютере. |
| Треск / заикание | Уменьшите нагрузку на Wi‑Fi, или увеличьте `--latency-msec` на компьютере (например, `50` или `100`). |
| Не слышно в колонках компа | Это нормально — скрипт читает только копию звука (монитор), колонки работают как обычно. |
| Приложение не устанавливается | Убедитесь, что на телефоне разрешена установка из неизвестных источников. |

## 📱 О приложении для Android

- **Пакет:** `com.example.pcsoundreceiver`
- **Минимальный SDK:** 21 (Android 5.0+)
- **Права:** `INTERNET`, `WAKE_LOCK` (чтобы звук не прерывался при выключенном экране)
- **Интерфейс:** одна кнопка «Старт/Стоп» и статус
- **Размер APK:** ~17 КБ

Если нужно пересобрать приложение — откройте `android-receiver/` в Android Studio. Gradle‑обёртка не включена в репозиторий, поэтому установите Android Studio и синхронизируйте проект.
