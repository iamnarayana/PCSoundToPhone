# PCSoundToPhone

Передача звука с компьютера (Linux/Arch) на телефон (Android) по Wi-Fi.

## Состав

- `linux-sender/pc-sound-sender.sh` — шлёт звук компьютера в сеть (UDP).
- `android-receiver/` — приложение для Android, принимает звук и играет его.

## Как работает

1. На компе запускаешь скрипт, указываешь IP телефона.
2. Скрипт берёт звук с «монитора» колонок (то, что ты слышишь) и отдаёт по UDP.
3. На телефоне запускаешь приложение, нажимаешь «Старт» — звук идёт в динамики телефона.

## Требования

**Linux:** `parec` (pipewire-pulse/pulseaudio), `socat` — уже есть в системе.  
**Android:** Готовый APK уже собран (`PCSoundReceiver.apk`, 17 КБ) — Android Studio не нужен.  
Минимальный SDK: 21 (Android 5.0+).

## Быстрый старт

### 1. Узнай IP телефона
На телефоне: *Настройки → Wi-Fi → нажми на подключённую сеть →看到 IP-адрес* (например, `192.168.1.42`). Телефон и комп должны быть в одной Wi-Fi сети.

### 2. Запусти отправку на компе
```bash
cd ~/Projects/PCSoundToPhone/linux-sender
chmod +x pc-sound-sender.sh
./pc-sound-sender.sh 192.168.1.42 9999
```
Остановка — `Ctrl+C`.

Параметры можно задать переменными окружения:
- `PCSOUND_PHONE_IP` — IP телефона
- `PCSOUND_PORT` — порт (по умолчанию `9999`)

### 3. Установи и запусти приложение на телефоне

**Вариант А (готовый APK — не нужен Android Studio):**
Установи готовый APK из этого репозитория: `PCSoundReceiver.apk` (17 КБ).
```bash
# с компа, если телефон подключён через USB и включена отладка:
/opt/android-sdk/platform-tools/adb install -r PCSoundReceiver.apk
```
Или просто скопируйте `PCSoundReceiver.apk` на телефон и откройте его — система предложит установить.
Нажмите **«Старт»** в приложении. Готово — звук с компа идёт на телефон.

**Вариант Б (через Android Studio):**
Открой `android-receiver/` в Android Studio → *Build → Make Project* → *Run*.


## Настройка задержки (latency)

По умолчанию задержка ≈ 100–300 мс. Можно уменьшить:

**На Linux (скрипт `pc-sound-sender.sh`):**
- `--latency-msec=20` — уже установлено (буфер захвата 20 мс).
- Если хотите ещё меньше — замените на `--latency-msec=10`, но при плохом Wi-Fi могут появиться перерывы в звуке.

**На телефоне (внутри приложения):**
- Буфер `AudioTrack` и размер UDP-пакета уменьшены до 2048 байт — это уже учтено в текущем APK.

## Решение проблем

- **Нет звука:** проверь, что комп и телефон в одной Wi-Fi сети; попробуй отключить фаервол на компе (`sudo systemctl stop nftables` / `ufw`) для проверки; убедись, что порт `9999` не занят.
- **Треск/заикание (подвигания звука):** уменьши нагрузку на Wi-Fi, или увеличь `--latency-msec` на комде (например, до `50` или `100`), либо увеличь буфер в коде Android-приложения.
- **Не слышно в колонках компа при передаче:** это нормально — скрипт читает только копию звука (монитор), колонки продолжают работать как обычно.
