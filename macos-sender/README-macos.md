# PCSound Sender — macOS

## Быстрый старт

1. Установите зависимости:
   ```bash
   brew install ffmpeg socat
   ```

2. Узнайте IP телефона (Настройки → Wi-Fi → сеть).

3. Запустите в терминале:
   ```bash
   cd /путь/к/PCSoundToPhone/macos-sender
   chmod +x pc-sound-sender.sh
   ./pc-sound-sender.sh 192.168.1.42 9999
   ```

4. На телефоне запустите приложение **PCSound Receiver**, нажмите **«Старт»**.

## Важное про системный звук на macOS

macOS **не позволяет** приложениям напрямую читать аудио, которое играет в динамиках. По умолчанию скрипт читает с устройства ввода по умолчанию (микрофон).

**Чтобы передавать именно звук компьютера:**

1. Установите **BlackHole** (виртуальное аудиоустройство): https://github.com/ExistentialAudio/BlackHole
2. В «Аудио настройках MIDI» создайте мульти-выходной класс: системный звук → BlackHole
3. В настройках звука macOS выберите BlackHole как устройство вывода
4. Запустите скрипт с указанием источника:
   ```bash
   PCSOUND_AUDIO_SOURCE="BlackHole 2ch" ./pc-sound-sender.sh 192.168.1.42 9999
   ```

Или просто читайте с микрофона (по умолчанию `:0`) — тогда в телефон будет идти звук с микрофона.

## Параметры

| Переменная / аргумент | Описание | Пример |
|----------------------|----------|--------|
| `$1` (IP-телефона) | IP адрес телефона в вашей Wi-Fi | `192.168.1.42` |
| `$2` (порт) | Порт UDP (по умолчанию 9999) | `9999` |
| `PCSOUND_AUDIO_SOURCE` | Источник аудио AVFoundation | `"BlackHole 2ch"` |
| `PCSOUND_PORT` | Порт UDP (альтернатива аргументу) | `9999` |

## Остановка

Нажмите `Ctrl+C` в терминале.
